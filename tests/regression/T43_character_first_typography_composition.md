# T43 — Character-First Typography Composition Regression

## A — 让我缓缓
Expected:
- character remains visually dominant and large;
- text stays close/integrated with character;
- `让 → 我 → 缓 → 缓` may progressively enlarge;
- spacing may loosen and baseline subtly descend to reinforce fatigue;
- text remains readable and does not cover the face/core gesture.

FAIL if:
- all characters use rigid identical size/spacing despite the intended fatigue rhythm;
- text is placed as a detached side block;
- character is shrunk mainly to make room for text.

## B — long copy on 1:1 canvas
Expected:
- reduce typography size before reducing character size;
- consider segmented, arc, semi-ring, staggered or controlled-overlap layout;
- preserve T41 maximum safe character occupancy.

## C — controlled overlap
PASS when text overlaps clothing/body without hiding eyes, mouth, identity anchors, core gesture or required prop.

## D — typography dominance
P1 FAIL when text becomes the largest visual mass and unnecessarily steals attention from the character.

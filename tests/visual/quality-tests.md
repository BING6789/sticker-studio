# Visual Quality Tests

- T21 Small-size readability: inspect at 200, 100, 50 px; warn if core reaction is unreadable.
- T22 Pose diversity: warn when a set relies excessively on the same silhouette/action.
- T23 Emotion duplication: warn when one semantic/emotional cluster dominates.
- T24 IP personality: warn when most lines could belong to any generic character.
- T25 Visual punch: warn when copy and action merely duplicate each other and a stronger contrast is available.

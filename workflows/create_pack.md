

## Wardrobe selection checkpoint
After MASTER_REFERENCE approval and before batch generation: decide whether the IP benefits from a wardrobe library; define 3–5 approved states when useful; assign WARDROBE_ID/base state during storyboard; prefer outfit-state changes before full outfit changes; verify identity after selection.

## Market-fit and series-icon checkpoints

Before IP/series commitment, run T39 Market Fit Matrix. Before producing the icon for an IP with earlier series, load the Series Icon Registry, choose an unused signature state, and run side-by-side small-size differentiation QC.

## Night-mode finalization checkpoint
Before final packaging:
1. apply T40 adaptive outline to text + main subject where needed;
2. preserve true transparency;
3. render white/light-gray/dark-gray/near-black previews;
4. inspect 240×240;
5. inspect smaller realistic chat preview;
6. run one-glance recognition test;
7. repair only failed assets; never regenerate approved art merely for contrast.

## Maximum-occupancy finalization checkpoint
Before final package export:
1. finish T40 outline;
2. compute final alpha/content bounds;
3. maximize safe occupancy for every main sticker;
4. maximize safe occupancy for the cover;
5. maximize head/face occupancy for the 100×100 icon;
6. correct visual center;
7. compare at realistic WeChat chat/store/selector size;
8. repair only undersized or clipped assets;
9. do not regenerate approved artwork for occupancy correction.

## Platform-review advisory checkpoints
Before copy lock, assign R0–R3 risk, explain meaningful risks and offer alternatives. Record the user's decision. Before packaging, review the final text+visual combination again. Do not alter approved copy or art without user instruction.

## T43 typography-composition checkpoint
Before generation, for each text-bearing sticker:
1. lock the strongest safe character composition first;
2. classify copy length and emotional rhythm;
3. choose text path around pose/gaze/gesture;
4. try typography adaptation (smaller type, hierarchy, arc, stagger, overlap) before shrinking character;
5. protect face/core gesture;
6. verify character remains primary visual;
7. run 240×240 and smaller chat-preview QC.

## V2.4 final composition gates
1. Run T44 Semantic Split Gate and Local Contrast Map before text lock.
2. Keep continuous phrases visually continuous; split only when meaning/action justifies it.
3. Finalize T40 night-mode safety edge.
4. Run T45 Mandatory Final Occupancy Pass on every sticker, cover and icon.
5. Fail delivery when obvious safe transparent margin remains.
6. Re-check at realistic WeChat UI size and peer comparison.
7. Occupancy repair is Pixel Safe; never regenerate approved art solely to fill the canvas.

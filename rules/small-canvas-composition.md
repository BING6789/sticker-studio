# Small-Canvas Composition
Final sticker canvas is 240×240. Default visual priority:
**Face/expression → upper-body gesture → key prop → body posture → legs/feet**.

Prefer head-and-upper-body dominant composition. Use full-body only when legs or whole-body action are semantically required (running, kneeling, lying down, kicking, etc.). Do not mechanically crop every sticker the same way.

Decision test: if removing the lower body does not reduce meaning, prefer upper-body composition.

P1 MUST FIX when unnecessary full-body framing makes the face or core gesture too small to read at chat size.

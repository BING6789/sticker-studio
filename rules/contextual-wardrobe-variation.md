# T35 — Controlled Contextual Wardrobe Variation

**Variation serves the copy; consistency serves the IP.**

Clothing is a controlled variable. The base/signature outfit remains the default. Change clothing only when the copy, scene, profession, emotional state or action is materially communicated better.

Decision order: **Expression → Action → Prop → Outfit**.

Allowed: contextually justified courtroom/formal/off-duty/relaxed clothing states.
Forbidden: random costume changes merely to create variety, unrelated cosplay, or wardrobe changes that overpower identity.

Even with clothing changes, preserve MASTER_REFERENCE identity: face, hair/ears/signature silhouette, age impression, body proportion, core palette/anchors, facial language and art style. Hide the copy: the character should still be immediately recognizable.

For paired stickers, keep wardrobe closely matched unless the clothing difference itself carries meaning.

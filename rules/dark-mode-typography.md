# Dark Mode Typography
Sticker text must remain legible on light and dark/night-mode chat backgrounds.

- Default: clear **white outline/stroke** around sticker text.
- Outline thickness adapts to font size/weight; do not use one rigid pixel width.
- Keep outline language visually consistent across the set.
- Preserve approved text fill/style unless explicitly changed.
- Check transparent original, light preview, dark/night preview, final 240×240, and smaller chat preview.

P1 MUST FIX: text merges into dark background, strokes disappear, or readability fails.
P2 WARNING: outline is excessively thick, fuzzy, or visually intrusive.

Thin Dog / 细狗 used dark text on transparent stickers. Night-mode readability was poor because QC lacked a dark-background preview. Permanent correction: white outline + dual-background/small-size QC.

# T44 — Semantic Reading & Local Contrast Typography

## Core principle
**Copy is language first, graphic form second.** Flexible typography must never destroy instant reading.

### Semantic Split Gate
A single semantic sentence defaults to one continuous visual reading unit. Do not split copy merely to fill empty space or create “design”.

Spatial splitting is allowed only when the copy itself contains a clear semantic relationship such as:
- question / answer;
- setup / punchline;
- contrast / turn;
- cause / result;
- two clauses bound to two distinct actions;
- a second clause that becomes a clear visual gag.

Positive case: `饼有了，钱呢？`
- `饼有了` may act as the setup;
- `钱呢？` may bind directly to an open palm, including appearing visually in/over the palm when readable;
- the split strengthens meaning rather than forcing the viewer to search.

Negative case: `让我缓缓`
- it may curve, stagger, enlarge progressively or change spacing;
- it must still read immediately as one continuous phrase;
- do not place two halves in unrelated locations.

### Reading Path Test
At realistic chat-preview size, the viewer must know where to start and how to finish the copy at first glance. If reading order requires searching the canvas, P1 FAIL.

## Local Contrast Map
Before placing text, classify image regions as:
1. CORE_PROTECTED — eyes, mouth, defining face features, key gesture, meaning-critical prop;
2. HIGH_CONFLICT — similar hue/value/texture to intended text, visually busy regions;
3. OVERLAP_SAFE — clothing/body regions that can support controlled text overlap;
4. OPEN_SPACE — clean negative space.

Text may overlap the character, but prefer OPEN_SPACE or OVERLAP_SAFE and avoid CORE_PROTECTED/HIGH_CONFLICT.

## Contrast resolution order
When text conflicts with character colors, resolve in this order:
1. reposition while preserving semantic relationship;
2. adapt text color/value within the approved IP typography family;
3. strengthen local separation/outline only as needed;
4. use a subtle local backing texture only as a last resort.

Do not default to a rectangular subtitle box. If backing is necessary, prefer a restrained soft/local/non-rectangular support that does not turn the sticker into a caption card.

### Multi-color characters
A multi-color character does NOT mean “never overlap text.” Find a low-conflict overlap zone instead. Do not retreat mechanically to character-left/text-right layouts.

## Severity
P1 MUST FIX:
- forced sentence split harms one-glance reading;
- ambiguous reading order;
- text merges with tie/clothing/character colors;
- text hides core face/expression/gesture;
- backing panel becomes visually dominant.

P2 WARNING:
- readable but text/character relationship feels detached;
- contrast works but could be cleaner with a better local region.

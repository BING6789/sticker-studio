# Quality Control

## File QC
count, dimensions, aspect ratio, format, true alpha/transparency, naming.

## Content QC
exact copy, punctuation, no clipping, no neighboring fragments, no unintended objects, no missing required effects.

## Character QC
locked face/body/clothing/palette/signature traits remain consistent.

## Small-size QC
Preview at 200×200, 100×100 and 50×50. Warn if face, text or core action becomes unreadable.

## Set QC
Check pose diversity, emotion diversity, semantic duplication, IP personality and overall sendability.

## Severity
P0 BLOCK: wrong size/format/transparency/count/explicit instruction.
P1 MUST_FIX: wrong text, clipping, artifacts, severe drift, unintended elements.
P2 WARNING: aesthetic/portfolio weakness.

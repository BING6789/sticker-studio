# T37 — Wardrobe Library & Selection Director

**Principle:** Default from a controlled library; select by scene; change clothing state before inventing a new outfit.

For suitable human/professional IPs, define 3–5 approved wardrobe states after MASTER_REFERENCE approval and before batch generation. Each entry records WARDROBE_ID, scene tags, colors, garments, clothing state, identity anchors, allowed variations and forbidden variations.

Selection order: **Expression → Action → Prop → Outfit State → Outfit Change**.

Base/signature clothing is the default, not mandatory for every sticker. If it already communicates the scene, keep it. Otherwise select an approved WARDROBE_ID. Prefer state changes—open jacket, loosened tie, rolled sleeves, jacket carried, collar opened, neat→slightly wrinkled—before a completely different outfit.

Wardrobe freedom depends on how strongly clothing defines the IP. Signature clothing anchors remain locked when identity-critical. Semantic pairs normally keep the same/related wardrobe unless clothing itself communicates the contrast.

Forbidden: random outfit rotation, unrelated cosplay, unapproved clothing when the library is sufficient, or wardrobe changes causing identity drift.

QC: P1 for random/unapproved wardrobe, identity drift, or loss of identity-critical clothing anchors. P2 for mechanical one-outfit repetition despite clear scene opportunities, or outfit novelty with no communicative value.

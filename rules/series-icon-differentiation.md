# T38 — Series Icon Differentiation

## Principle
**Single-icon recognition + cross-series differentiation.**

For the same IP, every pack icon must remain unmistakably the same character while being visibly different from prior series icons at small chat-strip size.

## Existing icon constraints remain
- 100×100 px
- PNG
- true transparency
- approved main-character large-head portrait / headshot
- no text
- no prop
- no extra character
- no decorative badge
- no tiny series number as a shortcut

## Differentiation priority
1. expression
2. head angle
3. gaze direction
4. mouth / brow state
5. controlled local clothing state when visible

Before creating a new series icon: load MASTER_REFERENCE and prior Series Icon Registry, choose a clearly unused signature state, then compare all same-IP icons side-by-side at 100×100 and smaller chat-strip preview size.

PASS: without reading pack names, adjacent same-IP series icons are quickly distinguishable while remaining clearly the same character.

P1: two same-IP series icons are easy to confuse, or character identity drifts to force differentiation.
P2: icons are technically different but perceptually too similar at small size.

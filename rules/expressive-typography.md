# T36 — Expressive Typography Director

## Principle
**Text is not a label; it is the visual form of the character's voice.**

Typography must respond to the copy, emotion, scene, character personality, and composition while remaining readable and recognizably part of the same IP.

## Two-layer system
### 1. IP Typography Identity
Define a stable typography personality for the pack:
- professional / restrained
- tired / loose
- mischievous / crooked
- round / lazy
- energetic / explosive
etc.

Do NOT interpret consistency as identical font, size, spacing, baseline, or layout on every sticker.

### 2. Copy Typography Performance
For each sticker, adapt only as needed:
- font family/variant within the approved typography family
- weight
- size
- size progression
- character spacing
- line spacing
- baseline / vertical rhythm
- tilt / stagger / directional flow
- keyword emphasis
- placement relative to face, gaze, gesture and action

Examples:
- weak/tired: loosen spacing, allow size progression/downward rhythm, softer visual weight
- surprise: larger jump, tighter impact, upward movement
- excitement/victory: stronger weight, upward/open rhythm, selective keyword emphasis
- hesitation: subtle instability/spacing variation
- speechless/low-energy: flatter, lower, more negative space
- professional judgment: clean, restrained, controlled hierarchy

## Keyword Emphasis
Do not emphasize a word merely because a keyword exists.
Choose one of:
- NONE
- LIGHT
- STRONG

Use emphasis only when it improves immediate comprehension or emotional rhythm and remains consistent with the IP.

LIGHT may use modest size/weight change.
STRONG may use a larger size/weight and, when appropriate, one approved accent color.

Avoid stacking too many effects. Normally use no more than 1–2 emphasis mechanisms.

## Hard constraints
- Dark-mode white outline/stroke remains required for text-bearing stickers.
- Text must remain legible at 240×240 and smaller chat-preview sizes.
- Typography must not obstruct the face, key gesture, necessary prop or effect.
- Avoid 24 unrelated fonts; use one typography identity with a small controlled family of emotional variants.

## QC
P1 MUST FIX:
- typography is mechanically pasted and materially weakens the intended emotion;
- expressive layout makes text unreadable;
- dark-mode outline is lost;
- keyword emphasis obscures meaning or core visual action.

P2 WARNING:
- every sticker uses identical typography despite clearly different emotional rhythms;
- excessive effects make the pack visually noisy;
- keyword emphasis is unnecessary or too promotional.

# Character Variation Director

## Core principle
Variation serves the copy; consistency serves the IP.

For every approved copy, design the smallest sufficient visual variation while preserving the approved MASTER_REFERENCE identity.

## Decision order
1. Expression
2. Action / gesture
3. Prop, only if useful
4. Outfit, only when the scene genuinely requires it

Priority: **Expression → Action → Prop → Outfit**.

## Locked identity
Species/identity, age impression, face shape, body proportion, hair/ear/signature silhouette, primary palette, signature anchors, core facial language and base art style remain locked.

## Variable elements
Expression, gaze, pose, gesture, direction, emotion intensity, useful prop, scene-required outfit and composition may vary.

Base/signature clothing remains the default. Outfit changes are not allowed merely to create variety.

## Production card
COPY / CORE_EMOTION / FACE / ACTION / OUTFIT / PROP / CHARACTER_LOCK / VARIATION_LEVEL / WHY

## QC
- Copy-Driven Variation: variation must serve the copy.
- Character Identity Preservation: hide copy/clothing and the character should still be recognizable.
- Minimal Sufficient Variation: no unnecessary prop/costume/effect.

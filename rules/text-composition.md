# Text Composition Director
Text is part of the sticker composition, not a pasted label.

- Place text per sticker according to pose, face, gaze, gesture, props, effects, negative space and visual center.
- Never force all stickers to the same coordinate or top/bottom zone.
- Keep font/style coherent across the set, but adapt position, alignment, line breaks and size.
- Do not cover faces, signature gestures, key props, action silhouettes or important effects.
- Validate at 240×240 and smaller chat-preview sizes.
- Preserve approved wording unless the user explicitly changes it.

QC: P1 for obstruction/unreadability/severe imbalance; P2 for mechanical repeated placement or weak integration.

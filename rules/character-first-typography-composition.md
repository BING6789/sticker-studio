# T43 — Character-First Typography Composition

## Core principle
**The character is the primary visual; typography performs with the character.**

Text must not force the character to become materially smaller merely to create a separate text block. On a 1:1 sticker canvas, typography should attach to, flow around, overlap with, or react to the character/action when that produces a stronger sticker.

## Visual priority
1. face / expression;
2. core action / gesture;
3. recognizable IP silhouette;
4. typography performance;
5. secondary prop / effect.

## Character-first layout
Start with the character at the strongest safe size under T41. Then find a typography path around the approved pose, gaze, gesture, silhouette and negative space.

Do not default to:
- character on one side + rigid text block on the other;
- text above + character below;
- identical text coordinates across a pack.

## Proximity
Text should normally form an obvious visual relationship with the character. Avoid detached captions floating far away unless distance itself communicates the scene.

## Copy-length adaptation
These are composition defaults, not rigid font-size limits:
- 1–3 Chinese characters: may be large/strong and close to the action;
- 4–6 characters: medium or smaller type, flexible line breaks and staggered layout;
- 7+ characters: prefer smaller type, segmented paths, arcs, semi-rings, controlled overlap or mixed hierarchy rather than shrinking the character.

## Allowed spatial forms
Encouraged when semantically useful:
- arc / semi-ring / partial circular flow;
- staggered lines;
- diagonal or directional flow;
- stepped baseline;
- text following head, ear, shoulder, arm or motion contour;
- controlled overlap onto clothing/body or low-information silhouette regions;
- keyword hierarchy;
- per-character size progression.

## Controlled overlap
Text may enter the character alpha region when it improves composition.

Avoid covering:
- eyes;
- mouth / essential facial expression;
- identity-critical facial features;
- core gesture;
- meaning-critical prop.

Overlap should integrate text with the sticker, not obscure the character.

## Typography as acting
Font size, spacing, baseline and direction may change *within one sentence* to perform emotion.

Supported mechanisms include:
- progressive enlargement: growing weight, fatigue, emphasis, excitement;
- progressive reduction: fading, retreating, losing confidence, moving away;
- expanding/contracting spacing;
- rising/falling baseline;
- one keyword jumping larger;
- controlled rotation/stagger;
- arc or motion-path typography.

Normally use only the mechanisms needed for the copy. Do not decorate mechanically.

### Positive regression example — 让我缓缓
For a tired/exhausted character, `让 → 我 → 缓 → 缓` may progressively increase in size while spacing loosens and the baseline subtly sinks. The typography should feel heavier/slower toward the final `缓`, reinforcing fatigue without overpowering the face and pose.

### Other examples
- `那我可不困了`: smaller setup text, `不困了` jumps larger/upward as the character suddenly becomes alert.
- `撤了撤了`: later characters may shrink/recede along the exit direction as the character leaves.
- `我差点就信了`: controlled emphasis/pause around `差点`, with a slightly loose sarcastic rhythm.

## Relationship with T26 / T36 / T41
- T26 decides where text belongs relative to the visual.
- T36 controls expressive typography language and emotional rhythm.
- T41 keeps the character/asset at maximum safe visual occupancy.
- T43 resolves conflicts: **do not solve text placement by unnecessarily shrinking the character.** Instead adapt typography size/path/overlap first.

## QC
P1 MUST FIX:
- text is visibly detached from the character without semantic reason;
- rigid text block materially shrinks the character;
- typography becomes the dominant visual block when the character should lead;
- long copy is handled only by reducing character size;
- text covers eyes, core expression, key gesture or meaning-critical prop;
- expressive copy is rendered as mechanically identical typography when that materially weakens the emotion.

P2 WARNING:
- typography is readable but overly formal/rigid for the IP personality;
- text path could integrate more naturally with the pose;
- size progression/spacing/baseline could better perform the copy.

## Small-size and night-mode constraints
All expressive typography must remain readable at 240×240 and realistic smaller chat preview sizes. T33/T40 contrast treatment remains mandatory. Expressiveness must not create jagged, fuzzy or cluttered text.

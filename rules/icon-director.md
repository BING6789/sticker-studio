# WeChat Icon Director

## Hard specification
- **100×100 px**
- 1:1
- PNG
- transparent background
- approved main-character **large-head portrait / headshot**
- head dominant and recognizable at 100×100

## Forbidden
- text or slogan
- props
- decorative elements
- extra action
- extra character
- scene clutter

Use the approved MASTER_REFERENCE. Do not simply shrink a full-body sticker. Compose a dedicated headshot while preserving identity.

The former **50×50** icon specification is deprecated and MUST NOT be used for final delivery.

## QC
Wrong dimensions/format/transparency = P0 FAIL. Text, decoration, prop, extra action/character, or unsuitable non-headshot composition = P1 MUST FIX.

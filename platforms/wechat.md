# WeChat Platform Profile — V1.2

This profile is the current project delivery contract. If the platform's official requirements change, the latest verified official requirements override this stored profile.

## Main stickers
- User-approved count, 1–24 stickers.
- 240×240 px.
- PNG.
- True transparent background.

## Cover
- 240×240 px.
- PNG.
- True transparent background.
- Must represent the approved IP clearly.

## Avatar icon
- 50×50 px.
- PNG.
- True transparent background.
- Must remain recognizable at very small size.

## Banner
- 750×400 px.
- PNG.
- Light background.
- Prefer an approved representative sticker/character asset and preserve identity.

## Text deliverables
- Name.
- Introduction/description.

## Final delivery
- Approved main stickers.
- Cover.
- Avatar icon.
- Banner.
- Name.
- Introduction.
- ZIP.

No final package may be released before platform QC passes.

## V1.7 consolidated visual delivery rules
- Main stickers: user-approved count, 1–24; 240×240 PNG; true transparency.
- Cover: 240×240 PNG; true transparency.
- Icon: 100×100 PNG; true transparency; approved main-character large-head portrait; no text/props/decorations/extra character.
- Banner: 750×400 PNG; light background; exactly one approved representative sticker; no added pack title/slogan/promotional text/second sticker/extra decoration.
- Text placement is composition-aware, not fixed.
- Typography may adapt to copy/emotion while retaining one IP typography identity.
- Selective keyword emphasis is NONE/LIGHT/STRONG; never mandatory.
- Text-bearing stickers default to adaptive white outline and must pass light + dark/night-mode readability QC.
- At 240×240, prioritize face/expression and upper-body action unless full-body information is semantically required.
- Check alpha bounding box and perceived visual weight to prevent excessive transparent margins making a sticker appear smaller than the rest.
- Contextual outfit changes are allowed only when they improve the copy/scene and preserve character identity.

## V2.0 night-mode safety
Every final WeChat sticker defaults to adaptive night-mode contrast treatment for both text and the main subject. The treatment must remain subtle on white/light backgrounds and immediately readable on dark/night backgrounds. Jagged edges, fuzzy halos, dirty fringes, clipping and obvious glow are P1 failures. Final QC includes white, light gray, dark gray and near-black backgrounds at 240×240 and smaller chat-preview size.

## V2.1 maximum safe occupancy
Main stickers, cover and icon should occupy the available platform canvas as fully as safely possible. Excess transparent margin is treated as a production defect when it makes the asset look smaller in WeChat UI. Final review must include realistic-size peer comparison. Night-mode T40 outline is included in the final bounds and must never be clipped.

## V2.2 review-risk advisory
`OJBK` and `真牛逼` are stored as user-verified rejected cases and should trigger R3 warnings. They are not automatic production blocks. After the warning, an explicit user decision to retain the wording is respected.

## V2.4 enforced final occupancy
T45 is a delivery gate, not a recommendation. Every 240×240 sticker, 240×240 cover and 100×100 icon must be finalized for maximum safe visual occupancy after T40. A small centered icon with large avoidable transparent margins is P1 and cannot be packaged as final. Text must also pass T44 one-glance reading and local-contrast checks.

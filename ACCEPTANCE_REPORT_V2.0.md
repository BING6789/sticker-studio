# Sticker Skill V2.0 Complete Acceptance Report

**Result: PASS**

## T40 — Adaptive Night-Mode Outline
The Skill now treats dark-mode readability as a full-sticker problem rather than text-only:
- character/subject + text receive adaptive night-mode safety treatment;
- outline is outward-only and anti-aliased;
- fixed universal stroke widths are forbidden;
- white/light backgrounds should show little or no obvious border;
- dark/night backgrounds must separate silhouette, face, gesture and text immediately;
- jagged, fuzzy, dirty, doubled, clipped or glow-like edges are P1 failures;
- white / light gray / dark gray / near-black previews are required;
- 240×240 and smaller realistic chat previews are required;
- one-glance recognition is mandatory;
- approved art is never regenerated just to add contrast.

## Completeness
V2.0 is built from V1.9 Complete and retains all prior executable structure and rules T01–T39.
